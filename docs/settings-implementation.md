## 已实现并接入行为

| 区域 | 本轮结果 |
|---|---|
| 分类框架 | 基础、账号、日程、任务、工作流、外观、通知、数据、快捷操作、关于；设置搜索 |
| 基础与外观 | 浅色/深色/系统主题、品牌色/自定义色、字体/字号、密度、日期/时间格式、左右侧栏、收起、搜索显示、快捷键显示、减少动画 |
| 日程与任务 | 默认视图、周起始日、时长、缩放时间步长、重叠样式；任务默认优先级与预计时间 |
| 提醒 | 提前量、强提醒间隔/次数通过同步应用到服务端日程提醒；提醒列表与确认 |
| 工作流 | 新节点类型、关联 Todo、优先级/时长、跳过依赖行为、自动解锁/手动解锁/开始依赖检查、连线名称、里程碑/说明/预计时间显示、缩放、自动布局 |
| 账号 | 资料编辑、密码修改、其他会话撤销、服务器账号注销；独立账号缓存和版本同步 |
| 数据 | 实际数量与大小、JSON 导入导出、每日首次保存自动备份、手动备份/恢复、分类清理、输入确认后清空；破坏性操作前快照与并发保护 |
| 头像 | 鼠标悬停或点击菜单，真实昵称/邮箱，个人资料、设置、切换账号、退出 |
| 关于 | 版本、使用帮助、开源许可；宽屏侧面板 |

截图示例数据仅用于测试，实际账号不填充虚构资料。登录页仍采用现有双栏表单，未复刻原图湖景插画或第三方登录按钮。
