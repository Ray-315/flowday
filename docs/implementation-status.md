# FlowDay V1 实现与验收

更新：2026-10-03。客户端采用 Flutter 原生桌面/移动工程，后端独立部署。用户已要求取消 Web/PWA 和 Inbox 导航，业务入口采用 Today 快速输入和智能安排。

## 已落地能力

| 模块 | 本次可用能力 |
| --- | --- |
| Today | 首张示意图默认布局；时间轴、任务、小日历、真实概览；模块显示与排序；节点、逾期、本周压力、通知摘要 |
| 任务与日程 | 状态、优先级、难度、预计/手动实际耗时、子任务、项目/标签；重复规则、结束日期/次数、本次或本次及以后；任务批选、归档和回收 |
| 日历 | 月/周/日/列表/时间轴；任务拖入、移动和缩放、重叠布局、锁定；所选时区与夏令时日界 |
| 项目 | 嵌套、移动、进度、归档、删除与恢复；任务/项目附件入口 |
| 工作流 | 七类节点、AND/OR依赖、分支选择、延迟、分组折叠/移动、跨项目跳转、框选、复制粘贴、撤销重做、小地图、日历关联 |
| AI | 模型结构化预览、歧义候选；三种排程策略、重排锁定保护、排除日期、部分应用、修改差异、审计撤销、失败后手动创建 |
| 提醒 | 独立多规则与逐对象强提醒、截止提醒；服务端队列、飞书个人机器人、限时签名动作；开始/完成/知晓/稍后/延后；原生通知适配器与授权入口 |
| 导入与同步 | CSV/JSON/ICS课程预览、冲突选择、课程项目；Apple CalDAV发现、加密连接、双向变更/删除、冲突选择与重复实例 |
| 搜索与报告 | 任务/日程/项目/节点/附件文本、键盘选择、任务完成；日报/周报/月报与自定义时间范围统计 |
| 数据 | 本地每日备份；云端日期备份恢复、SQLite快照；完整JSON与附件导出/原子导入，任务/日程/统计CSV；30天回收站清理 |
| 账号 | 邮箱验证码注册、发送与尝试次数限制；安全存储令牌、启动恢复、用户独立缓存；资料、密码、登录设备、注销；同步版本冲突保护 |
| UI | 全局HarmonyOS Sans SC、中文导航、共享深浅主题/按钮/选择菜单、原生许可页 |

## 已验证

- Flutter静态检查无问题；客户端186项自动测试通过。
- 后端61项测试通过，包括邮箱验证码、微软发信请求、真实HTTP模拟CalDAV、完整归档回滚、账号隔离、AI确认与提醒动作。
- Windows release编译通过；发布必须保留DLL及data目录。
- 桌面与手机尺寸的浅色/深色截图由真实Flutter组件生成，示例数据只用于测试。

## 完整体仍需的验收与配置

这些项目不能用模拟测试替代：

- 邮箱验证码已实现并部署；Microsoft 365 应用授权与 `Mail.Send` 已验证成功，发件邮箱错误已解决。Graph 发信返回 202，公网验证码接口返回 200；收件箱送达与客户端注册仍需实际确认。

- 2026-10-03 已部署到 `https://flowday.mtrx.pro`，Docker构建、Caddy代理、HTTPS与真实API联调通过。现场确认原有 `atrium-caddy` 占用80/443，FlowDay复用它并使用宿主机33108；未查到旧报错的原始记录。维护命令见[实际部署与维护](deployment-production.md)。
- Apple应用专用密码、飞书机器人和模型服务需真实账号联调；密钥只通过服务器环境变量或加密账号配置输入。
- 极简课程表专有导出尚无真实样本；现有CSV/JSON/ICS通用适配器已实现，不宣称已兼容未见过的格式。
- Android/iOS/macOS/Linux工程存在，但尚未完成对应平台发行构建和真机验证。系统通知权限、后台行为和移动端导出文件分享仍需平台验收；Linux通知依赖客户端运行。
- 第三方登录、两步验证、Google/Outlook同步没有实现。数据遥测和AI训练上传未添加。现有中文界面尚无完整英文翻译。
- PRD中的所有精细需求仍需逐条人工验收，包括每种原生系统的后台触达、附件外部分享、示意图全部交互细节。不能把“已有模块入口”视为每条验收项已完成。

当前版本是功能扩充并可打包的验收版本；上述事项通过后才能宣称V1完整验收。
